What you get

Everything an operations team needs to hand out access safely, and nothing that has to be installed on the client.

Access

  • Five protocolsRDP, VNC, SSH, Telnet and Kubernetes exec through Guacamole's guacd.
  • Per-user and per-group RBACShare connection lists with view, connect or edit rights.
  • Private connection spaceEvery user gets their own list with their own credentials. No admin ticket needed.
  • Ad-hoc connectionsAdmins can open a one-off session without saving a reusable record.
  • Proxied bookmarksReach internal-only web hosts through the platform.
  • DemosCurated bundles of connections and bookmarks, granted independently of normal lists.

In a session

  • Record and replayCapture in the browser, scrub a timeline, export to MP4.
  • Live session sharingInvite a colleague as viewer or interactive. Revoking ends their connection.
  • Clipboard syncBidirectional text copy and paste.
  • File transferDrag-and-drop upload with progress. RDP drive redirection and SSH SFTP for downloads.
  • Touch and audioTrackpad-style touch input for phones and tablets. RDP audio with an Unmute control.
  • Many sessions at onceTabs and keyboard shortcuts to move between them.

Admin and operations

  • Connections export and importMove or seed connection sets between instances.
  • Backup and restoreBack up the instance and bring it back.
  • Appliance imageReady-made OVA or portable QEMU bundle built with Buildroot.
  • Translatable UIEnglish, German, Greek, French and Italian today. Add a language by dropping in a JSON file, no rebuild.

How it fits together

A thin web tier in front of Guacamole's proven protocol daemon, with secrets and state kept in their own services.

1. Sign in

Password, Active Directory over LDAPS, or a passkey. Roles and group memberships decide what the user can see.

2. Connect

The backend decrypts the credential through Vault's Transit engine just in time and hands guacd a short-lived token.

3. Work

Pixels, clipboard, files and audio stream over a WebSocket tunnel. Every action lands in the audit log.

Built for teams who get audited

Credentials never sit in the database in the clear
Secrets are encrypted with HashiCorp Vault's Transit engine. Share one per connection, or let each user vault their own.
Passkeys
WebAuthn sign-in with no shared secret to phish. TOTP 2FA is enrolled for the first administrator during setup.
Active Directory
LDAPS login with optional group-membership sync, so access follows your existing groups.
Full audit trail
Who connected, to what, and when, with optional syslog forwarding to your SIEM.
Recorded and revocable
Sessions can be recorded and replayed. A shared session ends the moment the owner revokes it.
TLS your way
Optional Caddy overlays: public Let's Encrypt certificates, or an internal on-demand CA for private networks.

Up and running

You need Docker with the Compose plugin. The full guide, including TLS and Active Directory, is in the repository README.

  1. Get the code 
    git clone https://github.com/YOUR-GITHUB-USER/guac-access-suite.git
cd guac-access-suite
  2. Create your environment file 
    cp .env.example .env
# set strong random values for POSTGRES_PASSWORD, SESSION_SECRET,
# JWT_SECRET and GUAC_TOKEN_ENCRYPTION_KEY
  3. Start the stack

    From a source checkout, add the dev compose file so images are built locally.

    docker compose -f docker-compose.dev.yml up -d --build
  4. Initialise and unseal Vault

    Run it again whenever the Vault container restarts.

    ./scripts/vault-init.sh
  5. Open the setup wizard

    Browse to https://your-host/. The first run walks you through the instance name, the first administrator, TOTP and a theme.

Keep vault-init-keys.txt somewhere safe. It holds the unseal keys, and Vault cannot be recovered without them.

Make it yours

Four themes and five languages ship in the box. A new language is a single JSON file in the locales directory.
